# imagine-lab-3d

'만약에 | 3D 시뮬레이션' 세로 쇼츠 렌더 파이프라인 (Blender 4.2 LTS Cycles + Python).

- `episodes/` 주제별 시뮬레이션·장면·자막
- `engine/` 공통 3D 도구, 후처리(별·블룸·톤매핑), 자막 합성, 배경음 자동 작곡(FluidSynth)
- `.github/workflows/render.yml` GitHub Actions에서 병렬 렌더

자산 출처: Natural Earth(퍼블릭 도메인), NOAA ETOPO1(퍼블릭 도메인), Noto Sans KR(SIL OFL 1.1), FluidR3_GM 사운드폰트(MIT, 빌드 시 apt 설치).
